Self-contained demo: reservations live only in your browser and reset when you clear it. It enforces the real API's rules — one-hour slots, party sizes capped by table, no double-booking a confirmed slot, and cancelling frees the slot. It is written as a real API client: set API_BASE in the code to a running API and every action calls the live endpoints instead of the demo data.
